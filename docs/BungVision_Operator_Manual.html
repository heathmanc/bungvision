1

What BungVision Does

BungVision is a camera that watches each battery as it goes down the line. It looks at the top of the battery and checks that every bung is in place. A bung is the small round plug that seals each cell on top of the battery.

A good battery has all of its bungs. If a bung is missing, or the bungs are in the wrong spots, the battery is bad. BungVision uses a trained model (its "eyes and brain") to find the battery and count the bungs many times per second.

When BungVision sees a bad battery, it shows a big red REJECT LATCHED message and tells the machine (the PLC) to stop the line so the bad battery can be pulled off.

In plain words

BungVision = an automatic set of eyes that counts bungs and stops the line when a battery is wrong.

2

The Main Screen

This is the screen you will use all shift. The big panel on the left is the live camera and the result. The column on the right has your buttons and the machine status.

The parts of the screen

  • Result panel (big box, top left) — shows PASS, FAIL, or WAIT for the battery being checked, and the bung count like 6/6.
  • Camera view (below the result) — the live picture from the camera.
  • Status chips (top right corner) — quick health of the PLC, Camera, and Model.
  • Metric cards — Pass Rate, Rejects this session, and Inference (how fast the camera is thinking, in frames per second).
  • Operator Controls — the buttons you press: Run, Stop, Load Model, Settings, Reset Reject, Reset Counts, Production Summary.
  • Machine Interface — the lights that show what BungVision is telling the machine (heartbeat, stop request, alarm, ready).
3

Starting and Stopping

Before the line runs, BungVision needs its model loaded and its camera open.

  1. Load the model. Press Load Model. When it is ready, the MODEL chip at the top turns green. The model is the file that knows what a battery and a bung look like.
  2. Start the camera. Press Run. The camera view goes live and the CAMERA chip turns green.
  3. Watch the result panel. As batteries pass, you will see PASS, FAIL, or WAIT for each one.
  4. To stop, press Stop. The camera stops and BungVision tells the machine it is no longer running.
If the camera freezes

Press Run again. That closes and re-opens the camera. If it keeps stopping after about a minute, tell maintenance — the camera's USB power may be turning off (there is a one-time fix for this on the Jetson).

4

How PASS and FAIL Are Decided

For every battery, BungVision does the same simple check:

  • Find the battery in the picture.
  • Count the bungs that belong to that battery.
  • Compare the count to the number it should have (normally 6).

A PASS

The battery has all 6 bungs, and the bungs sit in a correct shape. Then the panel turns green.

A FAIL

The battery does not have exactly 6 bungs, or the bungs are in the wrong shape. Then the panel turns red.

What "WAIT" means

Sometimes you will see WAIT. That is normal. It means the battery is not all the way in view yet — it is still coming in from the edge of the picture. BungVision holds off on judging until it can see the whole battery. It will not call a battery bad just because it is half in frame.

The two extra checks

Two settings make the check smarter. A supervisor sets these on the Inspection tab.

RuleWhat it does
BungsHow many bungs a good battery must have. Default is 6.
Require full view before gradingHolds a battery in WAIT until the whole battery is on screen, so an edge battery is not called bad by mistake.
Validate bung patternChecks that the 6 bungs form a clean shape — either one straight row of 6, or a 2×3 grid. If they don't, it is a FAIL even when the count is 6.
PASS needs all three

Full battery in view and the right number of bungs and a correct pattern. Miss any one, and the battery is a FAIL (or a WAIT until it is fully in view).

5

When a Battery Is Rejected

The moment BungVision commits a FAIL, it does two things at once:

  1. It counts the fail. Your Rejects number goes up by one. This number is how you know the system is catching bad batteries.
  2. It latches the reject. "Latch" means it locks on and stays on. The panel shows REJECT LATCHED and BungVision turns on STOP REQUEST and ALARM to the machine so the line stops.

The reject stays locked until someone clears it. This is on purpose — it makes sure a bad battery cannot slip by without a person handling it.

Look at the Machine Interface lights

On a reject you will see STOP REQUEST and ALARM turn red, and Ready changes to Not Ready - Stopped. That is BungVision telling the machine to hold.

6

Clearing a Reject (Reset Reject)

When the line stops for a reject, here is what you do:

  1. Fix the battery. Pull off or repair the bad battery so the problem is gone.
  2. Press Reset Reject. This unlocks the latch. BungVision sends a reset to the machine and goes back to READY.
  3. Let it re-inspect. BungVision will look at the next (or fixed) battery again. It has to see a good battery before the line keeps running.

Reset Reject only clears the lock. It does not erase the fail from your count. That is on purpose — you still want to know how many bad batteries the system caught this shift.

The machine can reset it too

Your PLC can clear the reject on its own by turning on the BungVision_ResetRequest tag. BungVision watches that tag and, when it turns on, does the same thing as pressing Reset Reject. Ask a supervisor if your line uses this.

7

Reset Reject vs Reset Counts

These two buttons look alike but do very different jobs. Do not mix them up.

ButtonWhat it doesWhen to use it
Reset RejectUnlocks the current reject so the line can run again. Your counts stay the same.Every time the line stops for a bad battery, after you fix it.
Reset CountsSets the Parts, Pass, and Reject counters back to 0 and starts a fresh session. It also clears any active reject.At the start of a shift or when you change to a new product.
Easy way to remember

Reset Reject = "let me keep going."   Reset Counts = "start my numbers over." Use Reset Counts only at shift start, never just to clear a stop.

8

The Heartbeat and the PLC

The PLC is the machine's controller. BungVision talks to it over the network. A supervisor sets this up on the PLC tab, but you should understand the lights.

What the heartbeat is

The heartbeat is a signal that turns on and off over and over, like a pulse, the whole time BungVision is alive and talking to the PLC. The machine watches this pulse. As long as it keeps beating, the machine knows BungVision is awake and working.

If the heartbeat stops beating, the machine knows something is wrong with BungVision (it froze, lost power, or lost the network) and can stop the line for safety. Think of it like a person nodding "I'm still here" every half second.

The Machine Interface lights

LightMeaning
HeartbeatThe pulse that proves BungVision is alive. It should keep changing.
Stop / RunGreen when running normally; red STOP REQUEST when a reject wants the line stopped.
AlarmTurns on with a reject, for the stack light or horn.
ReadyGreen only when everything is healthy: running, camera open, model loaded, and no stop. Not green means BungVision is not ready to inspect.
Actual CameraThe real camera size and speed, like 2592x1944 @ 30.
PLC WritesShows if BungVision is really connected to the PLC.

Bypass (supervisor only)

The Bypass (Supervisor) check box lets a supervisor keep the line moving even when BungVision would ask it to stop. It is for setup and troubleshooting only. Bypass does not make the machine "Ready" — it only stops BungVision from sending the stop. Use it with care.

9

Production Tracking

Press Production Summary to see how the line is doing. This screen only shows numbers — you cannot break anything here.

  • Current Session — Parts, Pass, Rejects, and Pass Rate since the last Reset Counts. It also shows parts per hour.
  • Today — the same numbers for the whole day, across every session.
  • Today — Reject Breakdown — the reasons batteries failed (like 5/6 bungs), so you can see the most common problem.
  • Last 7 Days — one row per day, with the pass rate for each.
  • Today — By Hour — parts and rejects broken down by hour (scroll down to see it).
Save the numbers

Press Export CSV to save a spreadsheet of the history, or Open Logs Folder to find the saved files. This history stays even after BungVision restarts.

10

Settings

Press Settings to open the setup window. It has tabs across the top. Most operators never need to change these — a supervisor sets them.

The Reject Classes list lets you name shapes that should stop the line right away — for example a tipped-over battery. If the camera sees that shape, it rejects at once, without counting bungs.
